Privacy Policy — sync-pl

Last updated: October 10, 2026

sync-pl is a personal, non-commercial command-line tool that mirrors playlists owned by the user from Spotify into private playlists on the user's own Deezer and YouTube accounts.

1. Data accessed

  • Spotify: titles, artists and durations of tracks in the user's own playlists (via the Spotify Web API, with the user's own OAuth consent).
  • YouTube: with the user's OAuth consent (scope youtube), the tool reads the user's own playlists and creates/updates private playlists on the user's own channel.

2. Data storage

All data (OAuth tokens, playlist track identifiers, matched video IDs) is stored locally on the user's own computer (~/.config/sync-pl/). Nothing is uploaded to any server operated by the developer. The developer has no access to any user data.

3. Data sharing

No data is sold, shared, transferred or disclosed to any third party. The only external communications are the direct API calls to Spotify, Deezer and Google on the user's own behalf, using the user's own credentials.

4. Data retention & deletion

Local data can be deleted at any time by removing the ~/.config/sync-pl/ directory. Revoking the application's access in the Google account settings (https://myaccount.google.com/permissions) immediately invalidates its tokens.
